# AGENTS.md

Repo do portfólio **AC.RankAW Churn Benchmark** — benchmark de classificadores
interpretáveis aplicando o método `AC.RankAW Ponderado` (`[GF][PM-SD][TS]`)
à predição de churn. Documentação de projeto em `docs/DECISIONS.md` e
`software_design_document_sdd_churn_ac_rankaw_ponderado.md`.

## Agent skills

### Issue tracker

Issues vivem no GitHub Issues deste repo (via `gh` CLI). See `docs/agents/issue-tracker.md`.

### Triage labels

Vocabulário default das cinco labels canônicas de triage (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` na raiz + ADRs em `docs/adr/`. See `docs/agents/domain.md`.
